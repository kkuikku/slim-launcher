Slim Launcher

A slimmer version of Plasma's standard application launcher (Kickoff), without the category sidebar.

Features:
- App grid uses the full width of the popup
- Tabs at the bottom: Favorites, All Apps, Recent Apps, Recent Files, and one menu category of your choice (default: Chrome Apps); extra tabs can be switched off
- Grid/list button; each tab remembers its own choice
- System Settings button and a power menu with the actions you choose
- Optional gap between the popup and the panel
- Tab labels: icon and text, text under icon, or icons only

Requires Plasma 6.8. Based on Kickoff from Plasma 6.8.2; uses Plasma's internal launcher module, so a future Plasma release may need an update.
